Core Platform Modules & Architecture

Talent Hub & Dynamic Search

Authorized corporate partners can search verified students by department, skills, and projects. Students can toggle public CV visibility with full privacy controls.

MOD_ID: TALENT_HUB

Mentorship Calendar & Booking

Alumni and seasoned academics offer 1-on-1 mentorship sessions. Students book appointments seamlessly via integrated Calendly / scheduling workflows.

MOD_ID: MENTOR_SYNC

Automated PDF CV Builder

Dynamic client-side PDF rendering powered by React-PDF, exporting industry-standard Europass and modern hybrid CV templates straight from profile data.

MOD_ID: REACT_PDF

Security, Auth & Row Level Security (RLS)

Strict 6-tier Role-Based Access Control (RBAC: Student, Alumni, Faculty, Employer, Moderator, Admin) guarded by PostgreSQL Row Level Security (RLS) policies and encrypted server session cookies.
